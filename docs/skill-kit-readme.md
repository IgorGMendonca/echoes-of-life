# The Unspoken — Claude Code skill kit

Copy the `.claude/skills` directories into the root of your existing project, merging without overwriting unrelated skills. Alternatively copy individual skills to `%USERPROFILE%/.claude/skills/` for personal use across projects. Start Claude Code in the project and paste PROMPT.md. Skills can also be invoked by name, e.g. `/emotional-storytelling`.

Optional official Remotion skill installation: `npx skills add remotion-dev/skills`. The custom skills are instruction-only Markdown files; they do not install rendering engines, footage, audio, or API credentials. Install or configure those separately as needed. Review third-party code before running it. This kit has not been executed inside your Claude project.
