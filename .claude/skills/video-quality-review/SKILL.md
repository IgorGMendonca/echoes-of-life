# Quality gate
Score each category from 0–10 as a subjective editorial rubric, not a performance prediction: emotional authenticity, script originality, opening clarity, visual coherence, pacing, English naturalness, accessibility, and satisfying resolution. Revise weak categories (below 7) and rerun the review. No score substitutes for safety, evidence or rights checks.

## Blocking checks
- Age-appropriate supportive framing; no shame, diagnoses, fear amplification or false claims.
- Verifiable psychology claims with source notes, or remove claims.
- Original script and documented rights for footage/audio; no unauthorized music or assets in exported files.
- No invented tool outputs, analytics, footage or provenance.
- If AI disclosure is applicable, include a note for the publisher. Do not imply platform eligibility or approval.

## Technical verification
If rendering is possible, actually render and inspect beginning, middle and end frames plus transitions using available tools. Check resolution, duration, codecs, audio stream (or intentionally absent), captions, contrast, safe areas, spelling, audio clipping and black frames. Use ffprobe where available and run appropriate project checks. If a check cannot be performed, mark it unverified. Do not publish without authorization.

Deliver a concise QA report with real paths, measured technical properties, revisions made, unresolved blockers, and any steps the publisher must complete. Separate actual MP4 exports from scripts and previews.
